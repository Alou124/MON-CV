Création d’un projet React avec Vite
1. Étapes de création
Étape 1 : Vérifier Node.js et npm
node -v
npm -v
Étape 2 : Créer le projet
npm create vite@latest 001
Choisir React, puis JavaScript.
Étape 3 : Entrer dans le dossier
cd 001
Étape 4 : Installer les dépendances
npm install
Étape 5 : Lancer le serveur
npm run dev
Ouvrir l’adresse affichée dans le terminal pour accéder à l’application.
2. Rôle des dossiers et fichiers
• node_modules/ : contient les bibliothèques installées.
• public/ : contient les fichiers statiques accessibles directement.
• src/ : contient le code source de l’application.
• src/assets/ : contient les images et autres ressources.
• App.jsx : composant principal de l’application React.
• main.jsx : point d’entrée qui affiche React dans la page HTML.
• App.css : contient les styles du composant App.
• index.css : contient les styles généraux.
• index.html : page HTML de départ contenant l’élément root.
• package.json : contient les informations du projet, les dépendances et les commandes npm.
• package-lock.json : enregistre les versions précises des dépendances.
• vite.config.js : contient la configuration de Vite.
3. Types de fichiers indispensables
• .jsx : permet d’écrire des composants React avec JavaScript.
• .js : contient du code JavaScript.
• .css : permet de gérer le style.
• .html : définit la structure de la page web.
• .json : contient des données et des configurations.
4. Commandes importantes
• npm create vite@latest 001 : crée le projet.
• cd 001 : entre dans le dossier.
• npm install : installe les dépendances.
• npm run dev : lance le serveur de développement.
• npm run build : prépare la version de production.
• npm run preview : permet de prévisualiser la version de production.
