Étape 1 : Créer le projet nommé 001

npm create vite@latest 001 -- --template react-ts

Étape 2 : Accéder au dossier

cd 001

Étape 3 : Installer les dépendances

npm install

Étape 4 : Lancer le projet

npm run dev

Ouvrir l’adresse locale affichée dans le terminal pour visualiser l’application.

2. Rôle des principaux dossiers et fichiers

node_modules/ : contient les bibliothèques installées.

public/ : contient les fichiers statiques accessibles directement.

src/ : contient le code source de l’application.

src/App.tsx : composant principal de l’application.

src/main.tsx : point d’entrée de React ; affiche le composant principal dans la page HTML.

src/App.css : styles du composant principal.

src/index.css : styles globaux.

index.html : page HTML de départ contenant l’élément root.

package.json : contient les dépendances et les commandes du projet.

package-lock.json : enregistre les versions précises des dépendances.

vite.config.ts : configure Vite.

tsconfig.json : configure TypeScript.

3. Types de fichiers indispensables

.tsx : fichiers TypeScript contenant du JSX, notamment les composants React.

.css : mise en forme de l’interface.

.json : données structurées et configuration.
